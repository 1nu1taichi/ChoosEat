# ChoosEat

## 目的

毎食食べたものを簡単に記録するアプリ。

## 機能一覧

| # | 機能名 | 詳細 |
|---| -- | --- |
| 1 | 食べたものの記録 | 食べたものを記録する機能。 |
| 2 | 食べたものの一覧表示 | 記録した食べたものを一覧で表示する機能。 |
| 3 | 食べたものの編集 | 記録した食べたものを編集・削除する機能。 |
| 4 | レパートリー登録 | よく食べるものをレパートリーとして登録する機能。 |
